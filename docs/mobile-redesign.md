# 手机端全新体验（设计方案）

- 原则：打开就知道下一步点哪里；每个画面一个主按钮，其余功能收进明确的地方。功能必须与现有版本一致
- 方案页（三个方向、7 个画面示意、功能对照表）：https://claude.ai/artifact/EY7657qA3wR8AnWxpHTvc6
- 推荐方向 D（v2，用户提议）：像 Claude 手机端的侧边栏（新会议 / 历史会议 / 头像→设置与账号）+ 一键录音主屏，无标签栏
- 模式改场景名（待定甲/乙）：甲 = 对话互译 / 听懂对方 / 多人多语言 / 只记录，每个配一句解释
- 悬浮字幕所有模式可用，模式只决定窗口里几种语言；横向长条，宽度由 iOS 缩放档决定，估一行 14–18 汉字 / 30–40 英文字母、每种语言 2 行（待真机实测）
- 范围：只改手机布局（< 1024px，App 与手机浏览器），电脑版不动；录音/翻译/保存逻辑不改
- 步骤：① 网页改动（部署即生效）② 原生改动一起发 TestFlight（演示隐藏状态栏、导出走分享面板、悬浮字幕）③ 模拟器逐屏截图 + 按功能表逐项验证
- 待定：模式名甲/乙；新用户默认模式；手机浏览器是否也用新界面
